# Evidence boundaries

## Reproducible in this repository

Synthetic observations, detection logic, task lifecycle, simulated notification acknowledgement, CSV checklist, HTML alert, recovery, automated tests and generated n8n Code node parity. Review the committed output or regenerate it locally. No screenshots are fabricated and no real client data is included.

## Private deployment experience

A separate operational implementation used scheduled n8n monitors, Google APIs, a restricted shared spreadsheet, HTML email and a web developer handoff. Real workflow executions, writes, send acceptance and named editor permission were verified during deployment. Public evidence is intentionally limited to the independent fictional implementation. Authorized interview demonstration of the real system should use a separately approved redacted screen share; never disclose private execution IDs, credentials, client URLs, emails or workbook links.

## What is not proven

- A production revenue increase, ranking improvement or empirically measured labour savings.
- Public demo integrations to live Search Console, Gmail, Sheets, CRM or dashboard.
- A hosted GitHub Actions run until the repo is published and an actual run completes.
- An external n8n import execution; exact embedded code parity was tested locally.
- Exhaustive technical SEO coverage: the demo receives normalized observations rather than crawling raw HTML, inspecting APIs or parsing robots/redirect chains. Missing observations remain unknown and coverage may be incomplete if an adapter silently omits expected inputs. A real rollout must track expected URLs and stale data.
- Perfect exactly-once email delivery or concurrent writes; simulated acknowledgement is separate from resolution. Production requires an outbox/idempotency strategy and retry reconciliation.

The strongest interview walkthrough is: run tests, show the initial checklist, explain repeat suppression, demonstrate recovery, then explain measured time-savings methodology and which production adapters require authorization.
